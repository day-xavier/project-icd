# Analise de dados sobre o acesso a leitura na região nordeste no Brasil
### O projeto pretende analisar dados relacionados ao acesso à leitura, com ênfase em fatores socioeconômicos que podem influenciar na constância em ler, com o objetivo de identificar padrões e desigualdades e apoiar conclusões baseadas em dados.
